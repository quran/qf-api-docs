# Resources API

```python
from quran_foundation import QuranClient

client = QuranClient(client_id="YOUR_CLIENT_ID", access_token="APP_ACCESS_TOKEN")

translations = client.list_translations()
translation_info = client.get_translation_info(131)
recitations = client.list_recitations()
snapshot = client.get_resource_snapshot("translations", 131)
```

## Content Resource Sync

Bootstrap word-by-word translations with the resource content ID, then fetch the resource snapshot with the dedicated helper:

```python
page = client.sync_resources(
    params={
        "bootstrap": True,
        "resources": "word_by_word_translations:85",
    }
)
snapshot = client.get_word_by_word_translation_snapshot(85)
```

Follow `page["sync"]["next_page_url"]` while `page["sync"]["has_more"]` is true, then store the final `next_sync_token`. Use the same canonical `resources` filter for later incremental calls.

Only approved, shareable, translation-only one-word resources are available; transliterations are excluded. Snapshot records use snake_case fields: `id`, `resource_content_id`, `resource_id`, `word_id`, `language_id`, `language_name`, `text`, `priority`, and `updated_at`. They are returned in canonical `word_id`, `priority`, and `id` order.

Supported helpers:

- `list_recitations(params=None)`
- `get_recitation_info(recitation_id, params=None)`
- `list_translations(params=None)`
- `get_translation_info(translation_id, params=None)`
- `list_tafsirs(params=None)`
- `get_tafsir_info(tafsir_id, params=None)`
- `list_languages(params=None)`
- `list_chapter_infos(params=None)`
- `list_chapter_reciters(params=None)`
- `list_recitation_styles(params=None)`
- `list_verse_media(params=None)`
- `sync_resources(params=None)`
- `get_resource_snapshot(resource_group, resource_id, params=None)`
- `get_word_by_word_translation_snapshot(word_by_word_translation_id, params=None)`
