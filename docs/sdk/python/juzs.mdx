# Juzs API

```python
from quran_foundation import QuranClient

client = QuranClient(client_id="YOUR_CLIENT_ID", access_token="APP_ACCESS_TOKEN")

juzs = client.list_juzs(mushaf=6)
juz = client.get_juz(1, mushaf=6)
```

Without `mushaf`, `list_juzs()` returns every juz once per verse mapping set, so the list has
more than 30 entries. Pass a mushaf ID to get the juzs of one mapping set. The `mushaf` argument
needs `quran-foundation-api` 0.14.0 or later.

Supported helpers:

- `list_juzs(mushaf=None, params=None)`
- `get_juz(juz_id, mushaf=None, params=None)`
