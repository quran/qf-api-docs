# Server Quickstart

Purpose: Get the SDK working on the server in a few minutes.  
Use this when: You have a backend, worker, or cron job.  
Do not use this when: You only have browser or mobile code.  
Backend required: Yes.  
Allowed runtimes: Node.js, serverless functions, workers.  
Required credentials: A **Backend/server app** from Developer Console, its pre-live `client_id`, and its one-time `client_secret`.<br />
Minimal import: `@quranjs/api/server`.

## Install

```bash
npm install @quranjs/api
```

## Minimal Example

```ts
import { createServerClient } from "@quranjs/api/server";

const client = createServerClient({
  clientId: process.env.QF_CLIENT_ID!,
  clientSecret: process.env.QF_CLIENT_SECRET!,
  services: {
    gatewayUrl: "https://apis-prelive.quran.foundation",
    oauth2BaseUrl: "https://prelive-oauth2.quran.foundation",
  },
  // New Backend/server apps hold granular Content scopes. Remove this line
  // for credentials that hold `content`.
  contentScopeMode: "granular",
});

const chapters = await client.content.v4.chapters.list();
```

The explicit service URLs keep a new Console app and its credentials in pre-live. After production permissions are granted, switch the credentials and both service URLs to production together.

## Content Scopes

`contentScopeMode: "granular"` needs `@quranjs/api` 3.17.0 or later. It makes each Content call request the granular scope it needs, such as `content.quran.read` for `chapters.list()`, instead of `content`. A new Backend/server app is issued the [granular Content scopes](/docs/user_related_apis_versioned/scopes#granular-content-scopes) in place of `content`, so it needs this setting.

Credentials that hold `content` remove the line and keep the default `contentScopeMode: "legacy"`, which requests `content` exactly as before. Do not switch them to granular mode unless they were also granted the granular scopes: the token endpoint rejects a scope your credentials were not granted with `invalid_scope`.

## Add Search After Permission

Search requires additional permission in Developer Console. After Search permission is granted for the same environment used by `client`, add the call:

```ts
import { SearchMode } from "@quranjs/api";

const results = await client.search.v1.query({
  query: "mercy",
  mode: SearchMode.Quick,
});
```

For signed-in user post mutations, see [QuranReflect Posts](/docs/sdk/javascript/quranreflect-posts).

## Common Mistake

Do not import `@quranjs/api/public` from backend code unless you are explicitly testing public-client behavior. The SDK has production defaults, so keep the pre-live `services` override while using a new Console app. Local maintainer testing instructions live in the SDK repo.
