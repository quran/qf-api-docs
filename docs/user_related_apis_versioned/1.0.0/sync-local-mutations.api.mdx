NOTE writes are private-only: saveToQR and attachedEntity are rejected with indexed 422 errors. NOTE CREATE requires a nonblank authenticated OAuth client_id; source attribution follows the existing server request-context policy. Use the direct note publication endpoint for QuranReflect publication.
