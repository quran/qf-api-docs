:::tip 🤲 Why Use Quran ID?
**We've built this for the Ummah so you don't have to.** By adding [Quran ID](/docs/quran-id) sign-in, you get:

- **Zero user management** — No database, no password resets, no account recovery
- **Cross-app sync** — Users' bookmarks, goals, and streaks can sync with Quran.com when your app is approved for the matching [User API](/docs/tutorials/oidc/user-apis-quickstart) scopes and the user consents to them
- **Single Sign-On** — One Quran ID works across Quran.com and connected apps

[Learn more about Quran ID →](/docs/quran-id)
:::

Please make sure you read our [User Related APIs Quickstart Guide](/docs/tutorials/oidc/user-apis-quickstart) or the [full integration guide](/docs/tutorials/oidc/getting-started-with-oauth2).
