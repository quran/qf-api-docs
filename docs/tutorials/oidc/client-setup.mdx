# OAuth2 Client Setup

Purpose: Explain how to create and configure your OAuth2 client.
Use this when: You are creating an app or updating client settings.
Do not use this when: Your client is already provisioned and you only need SDK code.
Backend required: Not for setup itself.
Allowed runtimes: Any.
Required credentials: None yet.
Minimal import: None.

## Configure Your Client In The Developer Console

Open the [Developer Console](https://dev-console.quran.foundation/projects),
sign in with your Quran Foundation account, and create your app. The console
issues credentials for the prelive and production environments and lets you:

- rotate your client secret;
- add each exact redirect URI and post-logout redirect URI separately; and
- request the API scopes your app needs and track their status.

## Important Question

Ask this clearly:

> Is my client confidential or public?

If Quran Foundation does not explicitly say your client is public, assume it is confidential and plan for backend token exchange.

For a confidential client, the browser should never hold `client_secret`. The backend or BFF keeps it, exchanges the code, refreshes the session, and stores tokens server-side. That is true even if your frontend runs on the edge.
