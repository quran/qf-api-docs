# OAuth2 Client Setup

Purpose: Explain what information Quran Foundation needs to create your OAuth2 client.
Use this when: You are requesting access or updating client settings.
Do not use this when: Your client is already provisioned and you only need SDK code.
Backend required: Not for setup itself.
Allowed runtimes: Any.
Required credentials: None yet.
Minimal import: None.

## Configure Your App in Developer Console

| Field                     | Why it matters                                |
| ------------------------- | --------------------------------------------- |
| App name                  | Shown to users on login and consent screens   |
| Redirect URIs             | Where users return after login                |
| Post-logout redirect URIs | Where users return after logout               |
| Website URL               | Lets users identify your app                  |
| Privacy policy URL        | Required for trust and compliance             |
| Terms of service URL      | Required for trust and compliance             |
| Logo URL                  | Optional, but improves consent screen clarity |

[Create an app](https://dev-console.quran.foundation/projects/new) or
[open an existing app](https://dev-console.quran.foundation/projects) in Developer Console,
then configure these details there. Add each redirect URI and post-logout redirect
URI exactly as your app will send it.

## Choose the App Type

The app type selected in Developer Console determines the OAuth2 client type:

- **Backend/server app:** A confidential client with a one-time `client_secret`. Keep the secret on the backend or BFF, exchange the code there, refresh the session there, and store tokens server-side. The browser should never hold the secret, even if the frontend runs on the edge.
- **Frontend or mobile app:** A public client with no `client_secret`. Exchange the code using PKCE, and send `client_id` without client authentication when refreshing.

Check the app type in Developer Console instead of guessing which flow to use.
