## Get the active App State configuration



Returns enabled data groups and effective limits for the authenticated OAuth client. Call it before writing so the app knows which names are available and which require ETag preconditions. Requires a user-delegated access token with app_state, app_state.read, or app_state.write. Client-credentials tokens are rejected because App State is always scoped to a real user.
