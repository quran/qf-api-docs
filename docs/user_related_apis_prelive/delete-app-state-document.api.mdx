## Delete an App State document



Deletes the live document and emits a tombstone. Deleting an absent document returns 204. Idempotency-Key is required; strict data groups also require a precondition. Requires a user-delegated access token with app_state or app_state.write. Client-credentials tokens are rejected because App State is always scoped to a real user.
