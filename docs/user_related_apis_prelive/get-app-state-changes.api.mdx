## Synchronize App State changes



Pulls a bounded page after an opaque sync token. Apply the page and nextSyncToken atomically; drain until hasMore is false. On 410, preserve pending mutations, bootstrap, drain, replay, then pull again. Requires a user-delegated access token with app_state or app_state.read. Client-credentials tokens are rejected because App State is always scoped to a real user.
