# Mushaf Fonts and Images

Content Sync provides Mushaf metadata, page mappings, and positioned words. It does not include font files or images. To see which Mushafs are currently available through Content Sync, bootstrap with `resources=mushafs:*`.

For font-based rendering, follow the [Font Rendering guide](/docs/tutorials/fonts/font-rendering/). It lists the supported font URLs and recommends loading fonts at runtime instead of storing them locally.

The table below identifies the rendering method for Mushaf IDs used in the Content API documentation. It does not grant additional rights to font or image files.

| ID | Mushaf | Rendering |
|---:|---|---|
| 1 | QCF V2 | Page-specific QCF V2 font |
| 2 | QCF V1 | Page-specific QCF V1 font |
| 3 | IndoPak | IndoPak font |
| 4 | Uthmani Hafs | Uthmani text |
| 5 | KFGQPC HAFS | QPC Hafs font |
| 6 | IndoPak 15 Lines | IndoPak font |
| 7 | IndoPak 16 Lines | IndoPak font |
| 10 | Uthmani Tajweed Images | Images |
| 11 | Uthmani Recite Quran Tajweed Images | Images |
| 12 | Black Images | Images |
| 14 | QPC Hafs Nastaleeq 15 Lines | QPC Nastaleeq font |
| 15 | QPC Hafs Nastaleeq 16 Lines | QPC Nastaleeq font |
| 16 | QPC Hafs with Tajweed | QPC Hafs font |
| 19 | QCF V4 Tajweed | Page-specific QCF V4 font |

For page and verse layout behavior, see the [Page Layout guide](/docs/tutorials/fonts/page-layout/).
